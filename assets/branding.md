# Red Tunic branding

The crimson cloak mark in `red-tunic.png` was created for Red Tunic with AI image generation from a text description. `red-tunic.ico` uses the same artwork at desktop icon sizes. The release artwork uses the Red Tunic mark on Windows and Linux.

The wireframe mesh badge in `red-tunic-mesh.svg` is original vector artwork for the project.

Red Tunic is an independent project. The game title and AMD Radeon names identify compatibility. Their respective owners retain their rights in those names and products.

The README previews render the Windows Builder’s own UI. They use an example installation path and include no gameplay or user data.

The README section graphics in `assets/marketing/` are original SVG artwork. The handheld outline identifies the Linux/Steam Deck development focus and is not a Valve logo or a verified performance badge. `docs/images/red-tunic-440-gameplay.png` is a local validation screenshot; game imagery remains Nintendo’s. Official IGN videos are linked with attribution and are not labelled public domain.
