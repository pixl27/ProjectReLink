05 / BEFORE YOU START

The useful
details.

Does this include the game?

No. Red Tunic ships source and build tools. You supply your own supported game, and the native game is built locally.

Is Steam Deck performance verified?

Not yet. Linux and controller-friendly handheld play are development targets. Published measurements identify the actual Radeon Vega reference PC; they should not be read as Deck results.

Will an update erase my shaders or saves?

Keep your existing output folder when updating a standalone build. The 4.4.0 changes preserve the shader translator and cache format, but cache compatibility still depends on GPU, toolchain and configuration. RecompLauncher keeps its separate data under recompdata.

Is this an official Nintendo project?

No. Red Tunic is an independent, unofficial project based on Hookshot. Nintendo, AMD, Valve and IGN retain their respective trademarks and media rights.
