# Longshot mesh fallback review

Longshot commit `9eabf8bc3` targets cold mesh fallback compilation on AMD's Windows driver. It selects workgroup memory for eligible task and mesh warps when the subgroup can exceed 32 lanes and compute cannot be pinned to 32. That includes Polaris and Vega. Mesa Intel keeps its shared warp default, RADV and the other drivers keep their existing defaults. The upstream report cites individual 53 to 310 second compiles on older Windows Polaris drivers. Its RADV comparison found FPS within noise. Windows Vega compile time and steady frame time still need local measurement.

The port includes the acquire and release operations that publish lane data. The shared warp cache flag moved to an unused bit so older cached code for that path is regenerated. The runtime flag contributes no bits when shared warp is off. The build-wide translator source hash can still change because the port edits the SPIR-V emitter. No prebuilt SPIR-V headers or local cache files were edited. Force a comparison with `RX_VK_MESH_SHARED_WARP=0`; check the effective setting, compute compile times and shared warp wait failures in both runs.

I reviewed the 51 renderer-touching commits between the Red Tunic history and the fetched Longshot head `86b3b9e4f`. The most relevant separate candidates are `682a66403` (culling reads wait on their own bytes), `b9bd74a25` (texture handle table bounds), `658e5f2ba` (GPU ASTC decoder scratch and loop hoisting), `1b0a17a82` (automatic recorder thread) and `b654a23a9` (small RAM startup cache handling). Each changes a different path and needs its own baseline. The turf floor fix `8dce60edc` depends on the adaptive turf feature, which this branch does not have. RDNA WMMA16 and native mesh changes do not speed up Vega's compute fallback.

Red Tunic already carries the texture handle count fix and the LDS GPU ASTC decoder. The follow-up ports the startup preload guard and recorder-only Auto mode on unmirrored systems with at least six usable physical cores. The local byte-range wait override is independent of both.
