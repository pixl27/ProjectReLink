# Red Tunic 4.0.6

- Windows Radeon Vega 1002:15E7 reuses exact decoded ASTC pixels. Cache hits require matching compressed bytes and decode shape.
- Texture prediction saves its list on light frames and releases its registration lock before writing.
- The README includes a Vega rendering diagram, a hardware guide and measured comparisons.
- The Windows download contains the Red Tunic Builder. Build or update your local game using the Builder.
